# Ошибки

Все ошибки API возвращаются в едином формате. Способ доставки зависит от транспорта:

- **WebSocket callback** — объект ошибки кладётся в поле `data` callback-кадра (см. [connection.md](./connection.md)).
- **HTTP** — объект ошибки возвращается как тело ответа (HTTP 400; при ошибках токена — 401).

## Формат ошибки

```json
{
  "status": false,
  "message": "EMAIL_ALREADY_TAKEN :: 126801",
  "type": "error",
  "code": "126801",
  "reason": null,
  "details": null,
  "timestamp": "2026-09-21T12:34:56.789Z"
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `status` | `boolean` | Всегда `false`. |
| `message` | `string` | Человекочитаемый код ошибки с номером: `"<КОД_СТРОКА> :: <число>"`. |
| `type` | `string` | Тип ошибки; по умолчанию `"error"`. |
| `code` | `string` | Числовой код ошибки (строкой). |
| `reason` | `string \| null` | Техническая причина (обычно `null`). |
| `details` | `any \| null` | Дополнительные данные (обычно `null`). |
| `timestamp` | `string` | ISO 8601 время возникновения ошибки. |

Поле `code` уникально для каждой проверки и меняется между версиями сервера —
клиент должен полагаться на `message` как на стабильный идентификатор ошибки.

## Типовые коды

Для валидации входящих данных используются следующие шаблоны названий (в `message`):

| Шаблон | Смысл |
| --- | --- |
| `*_REQUIRED` | Обязательное поле не передано (или пусто). |
| `*_INVALID` | Значение не прошло валидацию (формат, диапазон, regex). |
| `ACCESS_DENIED` | Недостаточно прав для действия. |
| `*_NOT_FOUND` | Сущность не найдена (пользователь, канал, сообщение и т.п.). |
| `*_ALREADY_TAKEN` | Занято (email, link и т.п.). |
| `INVITE_INVALID` / `INVITE_EXPIRED` / `INVITE_MAX_USES_EXHAUSTED` | Проблемы с приглашением. |
| `INTERNAL_SERVER_ERROR` | Непредвиденная серверная ошибка (на неё заменяются системные исключения). |

Полный перечень кодов ошибок приводится вместе с описанием каждого метода в разделе
[client-to-server](./websocket/client-to-server/README.md).

## Особые случаи

- **JSON-кадр без полей `type`/`event`** — сервер шлёт ошибку напрямую (не callback).
- **Событие без обработчика** — callback с `error` в виде текста и `data: null`.
- Многие обработчики требуют обязательный `callbackId`; без него сервер может вернуть ошибку `"Не передан: callback"`.
