# server-to-client: звонки

Push-события раздела `[call]` доставляются на **все активные соединения**
получателя. Полный сценарий — в [calls.md](../client-to-server/calls.md).

> Принятие, выход и завершение звонка не пушатся отдельными WS-событиями:
> участники видят их по событиям LiveKit-комнаты (см. [гайд WebRTC / LiveKit](../../guides/webrtc.md)).

## `[call]: incoming` — входящий звонок

```json
{
  "call_id": "UUIDv7",
  "user_id": "UUIDv7",
  "display_name": "Иван Петров",
  "avatar": null
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `call_id` | `string` | Id звонка — передаётся в `[call]: accept` / `decline` / `leave`. |
| `user_id` | `string` | Кто звонит (или кто добавляет в групповой звонок). |
| `display_name` | `string` | Отображаемое имя звонящего. |
| `avatar` | `object \| null` | Документ аватарки звонящего; приходит при первом вызове (может отсутствовать). |

## `[call]: declined` — звонок отклонён / отменён

```json
{ "call_id": "UUIDv7", "user_id": "UUIDv7", "reason": "declined" }
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `user_id` | `string` | Кто отказался от участия (при `cancelled` — инициатор, отменивший звонок). |
| `reason` | `string` | `"declined"` (нажал «Отклонить») \| `"timeout"` (никто не ответил за таймер) \| `"cancelled"` (инициатор отменил звонок до ответа). |

Кому приходит:

- **инициатору** — когда участники отказались/не ответили и в звонке никого
  не осталось (`reason: "declined"` / `"timeout"`);
- **приглашённым** — когда инициатор отменил ещё не принятый звонок
  (`reason: "cancelled"`).

В обоих случаях звонок завершается — форму звонка нужно закрыть.
