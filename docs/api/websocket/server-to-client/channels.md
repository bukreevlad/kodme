# server-to-client: каналы

События раздела `[channel]`. Основной объект — [Channel](../../objects/channel.md).

## Синхронизация и события канала

У каждого канала есть счётчик `last_pts` — позиция в ленте событий канала.
Живая доставка и догонка используют **единый формат события**: тип события,
`channel_id`, `pts` и `payload`. Клиент применяет события по порядку `pts`
и дедуплицирует их по `pts`.

```json
{
  "type": "event",
  "event": "[channel]: feed",
  "data": {
    "channel_id": "UUIDv7",
    "type": "message_new",
    "pts": 123,
    "payload": { "message_id": "UUIDv7" }
  },
  "timestamp": "2026-09-21T12:34:56.789Z"
}
```

Событие доставляется в комнату `channel::<channel_id>`.

### Правило применения

- `pts` равен последнему применённому + 1 — примените событие и запомните `pts`;
- `pts` меньше или равен уже применённому — пропустите (дубль);
- иначе (пропуск) — догоните недостающие события запросом
  `[channel]: get updates` (см. ниже);
- канал, точка которого отрезана лентой (он попал в `too_long`), перечитывается
  целиком: история + метаданные канала + участники + темы.

### Типы событий

| `type` | `payload` | Действие клиента |
| --- | --- | --- |
| `message_new` | `{ message_id, data? }` | Живой толчок несёт готовое сообщение в `data` — примените его. Нет `data` (догонка) — подгрузите сообщение (например, `[message]: get data`) и покажите его. |
| `message_edit` | `{ message_id, data? }` | Обновить сообщение: готовый объект из `data` заменяет прежнее состояние. Нет `data` — перечитайте сообщение. |
| `message_deleted` | `{ message_ids: ["UUIDv7", ...] }` | Удалить перечисленные сообщения (массив может содержать несколько id — массовое удаление это одно событие). |
| `history_cleared` | `{}` | Очистить локальную историю канала: история очищена у всех участников. |
| `messages_cleaned` | `{ author_id, channel_id }` | Удалить из канала все сообщения автора (чистка модерацией). |
| `member_joined` | `{ user_id }` | Обновить список участников. |
| `member_left` | `{ user_id }` | Обновить список участников. |
| `member_banned` | `{ user_id }` | Участник кикнут и заблокирован — обновить список участников. |
| `member_unbanned` | `{ user_id }` | Блокировка снята — обновить список участников (подписка не восстанавливается автоматически). |
| `channel_created` | `{ kind }` | Канал создан (`kind` — его вид): добавить канал, если он ещё не известен, и обновить его данные. |
| `channel_removed` | `{}` | Канал удалён или потерян — убрать его из списка. |
| `channel_updated` | `{ field }` | Изменены настройки — `field` определяет, что обновить: `settings` (настройки), `avatar` (аватар), `link` (ссылка), `moderators` (состав модераторов). |
| `topic_created` | `{ channel_id }` | В группе создана тема: получите данные темы (`[channel]: get info` по `channel_id`) и добавьте её в список тем группы. Событие приходит в ленте **группы** — догонкой по группе его увидят все участники. |

### `[channel]: get updates` — догоняющая синхронизация

Запрос события `[channel]: get updates` (см.
[channels.md](../client-to-server/channels.md)) возвращает события ленты,
которых нет у клиента:

Вход:

```json
{ "channels": [ { "id": "UUIDv7", "pts": 123 } ], "offset": 100 }
```

- `channels` — состояния каналов: `id` канала и последний применённый `pts`;
- `offset` — максимум событий в ответе, диапазон 1–100 (по умолчанию 35).

Ответ:

```json
{
  "items": [
    { "channel_id": "UUIDv7", "type": "message_new", "pts": 124, "payload": { "message_id": "UUIDv7" }, "created_at": "2026-09-21T12:34:56.789Z" }
  ],
  "has_more": false,
  "too_long": []
}
```

- `items` — события ленты (тем же форматом, что и живые `[channel]: feed`),
  по возрастанию `pts`;
- `has_more` — есть ли следующая порция событий;
- `too_long` — массив id каналов, чья точка отрезана лентой: по ним клиент
  обязан перечитать канал целиком, остальные каналы догоняются событиями.

Пример обработки: применяйте события из `items` по порядку `pts`; для
каналов из `too_long` сделайте полный снапшот (история + данные канала) и
запомните `last_pts` из объекта канала.

## `[channel]: user typing` — набор текста

```json
{ "user_id": "UUIDv7", "channel_id": "UUIDv7", "display_name": "…" }
```

Доставляется участникам в `channel::<channel_id>`.
