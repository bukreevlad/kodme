# server-to-client: пользователи

События раздела `[user]`.

## `[user]: online status` — изменение статуса присутствия

Сервер оповещает собеседников и контакты при подключении и полном отключении
пользователя.

**Онлайн** (пользователь подключился):

```json
{
  "user_id": "UUIDv7",
  "socket_user_id": "…",
  "status": "online"
}
```

**Офлайн** (закрыто последнее соединение пользователя):

```json
{ "user_id": "UUIDv7", "status": "offline" }
```

- `socket_user_id` присутствует только в событии `online` — это id соединения,
  через которое пользователь стал доступен (используется в сигналинге звонков).
- Если у пользователя остались другие активные соединения — событие `offline`
  не отправляется.
