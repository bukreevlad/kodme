# server-to-client: пользователи

События раздела `[user]`.

## `[user]: online status` — изменение статуса присутствия

Сервер оповещает собеседников и контакты при подключении и полном отключении
пользователя.

**Онлайн** (пользователь подключился):

```json
{
  "user_id": "UUIDv7",
  "socket_user_id": "…",
  "status": "online"
}
```

**Офлайн** (закрыто последнее соединение пользователя):

```json
{ "user_id": "UUIDv7", "status": "offline" }
```

- `socket_user_id` присутствует только в событии `online` — это id соединения,
  через которое пользователь стал доступен (используется в сигналинге звонков).
- Если у пользователя остались другие активные соединения — событие `offline`
  не отправляется.
## `[user]: feed` — личная лента событий

Живой толчок событий о появлении и исчезновении каналов у пользователя.
Доставляется в комнату `user::<user_id>`; догоняющая синхронизация —
запросом `[user]: get updates` (см.
[users.md](../client-to-server/users.md)), события одного формата.

```json
{
  "type": "event",
  "event": "[user]: feed",
  "data": {
    "upid": 124,
    "type": "channel_created",
    "payload": { "channel_id": "UUIDv7" }
  },
  "timestamp": "2026-09-21T12:34:56.789Z"
}
```

### Правило применения

- `upid` равен последнему применённому + 1 — примените событие и запомните
  `upid`;
- `upid` меньше или равен уже применённому — пропустите (дубль);
- иначе (пропуск) — догоните недостающие события запросом
  `[user]: get updates`.

### Типы событий

| `type` | `payload` | Действие клиента |
| --- | --- | --- |
| `channel_created` | `{ channel_id }` | У пользователя появился канал (диалог, добавили в группу/канал, создал сам): получите данные канала (`[channel]: get info`) и добавьте его в список. |
| `channel_removed` | `{ channel_id }` | Канал исчез у пользователя (удалён, выкинут, вышел): уберите канал из списка. |

Типы событий `channel_created` / `channel_removed` совпадают с событиями
[ленты канала](channels.md), но относятся к списку каналов пользователя, а не
к содержимому канала. Содержимое каналов догоняется `[channel]: get updates`.
