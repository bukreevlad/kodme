# dialogs — личные диалоги

События раздела `[dialog]`. Диалог — канал типа 1 (личный чат), с ботом — типа 8.

## `[dialog]: create` — создать диалог

```json
{ "user_id": "UUIDv7" }
```

Ответ: `{ "channel_id": "UUIDv7" }`.

Если диалог уже существовал — возвращается id существующего канала. Оба участника получают push `[channel]: new`.

## `[dialog]: create bot` — создать диалог с ботом

```json
{ "bot_id": "UUIDv7" }
```

Ответ: `{ "channel_id": "UUIDv7" }` (канал типа 8).

## `[dialog]: remove` — удалить диалог

```json
{ "channel_id": "UUIDv7", "for_all": false }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `for_all` | `boolean` | `false` | Удалить у обоих участников. |

Ответ — пустой.
