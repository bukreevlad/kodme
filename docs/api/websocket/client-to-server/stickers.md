# stickers — стикер-паки

События раздела `[sticker]`. Модуль включается флагом `server.modules.stickers` в `config.yaml`.
Основной объект — [StickerPak](../../objects/stickerpak.md).

Пак — набор стикеров (картинок WEBP), собранный пользователем. Публичные паки
видны всем и доступны для подписки («Добавить к себе»), приватные — только
автору. Стикер из пака, видимого отправителю, можно отправить сообщением —
см. `[message]: send` (поле `sticker_document_id`) в [messages.md](./messages.md).

Лимиты: название ≤ 64 символов, описание ≤ 255; файл стикера — только WEBP,
стороны ≤ 512 px, размер ≤ 512 КБ; стикеров в паке ≤ 100.

## `[sticker]: get paks` — список паков

```json
{ "offset": 0, "limit": 50 }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `offset` | `int` | `0` | Смещение (≥ 0). |
| `limit` | `int` | `50` | Количество записей (1–100). |

Ответ — массив паков (публичные и свои, новые сверху) и поле
`has_more: boolean` — есть ли продолжение. Объект пака — в
[StickerPak](../../objects/stickerpak.md); поле `preview` содержит первые
4 стикера пака (`sticker_id`, `document_id`, `file_token`).

## `[sticker]: get pak` — пак со стикерами

```json
{ "pak_id": "UUIDv7" }
```

Ответ — объект пака c полным массивом `stickers`
(`{ "sticker_id": "UUIDv7", "document_id": "UUIDv7", "file_token": "..." }`,
порядок — по дате добавления). Приватный пак доступен только автору —
иначе `PAK_NOT_FOUND` (134303).

## `[sticker]: create pak` — создать пак

```json
{ "name": "Мои стикеры", "about": "Первый пак", "is_public": false }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | — | Название (1–64 символа). |
| `about` | `string \| null` | `null` | Описание (≤ 255 символов). |
| `is_public` | `boolean` | `false` | Публичный пак (виден всем) или приватный (только автору). |

Ответ — созданный пак (пустой `preview`, `stickers_count: 0`).
Ошибки: `NAME_REQUIRED` (134003), `INVALID_NAME` (134001),
`ABOUT_TOO_LONG` (134000).

## `[sticker]: update pak` — изменить пак

```json
{ "pak_id": "UUIDv7", "name": "Новое имя", "about": null, "is_public": true }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `pak_id` | `UUIDv7` | — | Id пака. |
| `name` | `string` | — | Новое название (не передано — без изменений). |
| `about` | `string \| null` | — | Новое описание (`null` — очистить, не передано — без изменений). |
| `is_public` | `boolean` | — | Новая публичность (не передана — без изменений). |

*Только автор пака* (иначе `NOT_PAK_AUTHOR` — 134904). Ответ — обновлённый
объект пака с полями `is_author` / `is_member`.

## `[sticker]: delete pak` — удалить пак

```json
{ "pak_id": "UUIDv7" }
```

*Только автор.* Пак удаляется вместе со связями стикеров; документы файлов
и отправленные ранее стикер-сообщения не затрагиваются. Ответ:
`{ "pak_id": "UUIDv7" }`.

## `[sticker]: subscribe` — добавить пак к себе

```json
{ "pak_id": "UUIDv7" }
```

Подписка возможна только на публичный пак (`PRIVATE_PAK` — 134706) и не на
свой (`OWN_PAK` — 134703); повторная подписка — `ALREADY_SUBSCRIBED` (134700).
Подписка переживает последующее закрытие пака автором. Ответ:
`{ "pak_id": "UUIDv7", "is_member": true }`.

## `[sticker]: unsubscribe` — убрать пак из своих

```json
{ "pak_id": "UUIDv7" }
```

Убирает подписку (`NOT_SUBSCRIBED` — 134802, если подписки нет). Ответ:
`{ "pak_id": "UUIDv7", "is_member": false }`.

## `[sticker]: get upload sticker url` — ссылка для загрузки стикера

```json
{ "pak_id": "UUIDv7", "file_name": "sticker.webp", "mime_type": "image/webp", "size": 65536, "metadata": {} }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `pak_id` | `UUIDv7` | — | Id пака. |
| `file_name` | `string` | — | Оригинальное имя файла. |
| `mime_type` | `string` | — | MIME-тип файла; сверяется с расширением. |
| `size` | `number` | — | Размер файла в байтах (≤ 512 КБ). |
| `metadata` | `object` | — | Метаданные (у стикера производных нет — пустой объект). |

*Только автор пака.* Формат — только WEBP (`WEBP_REQUIRED` — 134508),
лимит пака — 100 стикеров (`PAK_LIMIT_REACHED` — 134505). Ответ:

```json
{
  "targets": [
    {
      "path": "stickers/<user_id>/<pak_id>/<uuid>/<uuid>.webp",
      "kind": "original",
      "url": "https://...",
      "fields": { "key": "...", "Policy": "..." },
      "mime_type": "image/webp",
      "max_size": 524288
    }
  ],
  "document_id": "UUIDv7"
}
```

Загрузите `POST`-ом на `target.url` объект по подписанной политике (как
описано в [руководстве по файлам](../../guides/upload.md)), затем вызовите
`[sticker]: save sticker`.

## `[sticker]: save sticker` — сохранить загруженный стикер

```json
{ "pak_id": "UUIDv7", "document_id": "UUIDv7" }
```

*Только автор пака.* Сервер проверяет реальные размеры загруженного WEBP
(≤ 512 px по стороне, `INVALID_DIMENSIONS` — 134602), обрабатывает
изображение (создаются производные ассеты) и привязывает документ к паку.
Обработка может занять до ~100 секунд — таймаут запроса на клиенте должен
быть не меньше 120 секунд. При сбое обработки или истечении таймаута —
`MEDIA_PROCESSING_FAILED` — 134611. Ответ:

```json
{ "sticker_id": "UUIDv7", "document_id": "UUIDv7", "file_token": "...", "width": 512, "height": 512 }
```

`sticker_id` — идентификатор стикера для удаления, `file_token` — токен на
чтение файла (query `?token=…` ссылки хранилища).

## `[sticker]: delete sticker` — удалить стикер из пака

```json
{ "pak_id": "UUIDv7", "sticker_id": "UUIDv7" }
```

*Только автор пака.* Отвязывает стикер от пака: документ и отправленные
стикер-сообщения сохраняются. Ответ: `{ "sticker_id": "UUIDv7", "pak_id": "UUIDv7" }`.
