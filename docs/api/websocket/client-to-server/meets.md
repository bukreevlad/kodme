# meets — конференции

События раздела `[meet]`. Конференции работают через LiveKit; у каждой конференции есть
чат (канал типа 6). Основной объект — [Meet](../../objects/meet.md).

## `[meet]: create` — создать конференцию

```json
{ "name": "Еженедельная встреча", "about": null, "is_public": true, "is_chat": true }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | — | Название, `^[\p{sc=Cyrillic}\p{sc=Common}\p{sc=Latin}]{2,128}$`. |
| `about` | `string \| null` | `null` | Описание, до 255 символов. |
| `is_public` | `boolean` | `true` | Публичность. |
| `is_chat` | `boolean` | `true` | Создать чат конференции (канал типа 6). |

Ответ: `{ "meet_id": "UUIDv7" }`.

## `[meet]: get meets` — список конференций

```json
{ "direction": "next", "cursor_id": null, "offset": 35 }
```

`offset` — диапазон 1–100. Возвращаются публичные конференции и свои. Ответ — массив [Meet](../../objects/meet.md) (meta) **и** поле `has_more: boolean` — есть ли продолжение в сторону `direction` (для первой загрузки — есть ли продолжение после страницы).

## `[meet]: get info` — информация

```json
{ "meet_id": "UUIDv7" }
```

Ответ — объект [Meet](../../objects/meet.md) (meta). Доступ — публичная / владелец / участник.

## `[meet]: get settings` — настройки

```json
{ "meet_id": "UUIDv7" }
```

*Только владелец.* Ответ — объект [Meet](../../objects/meet.md) (meta).

## `[meet]: save settings` — изменение настроек

```json
{ "meet_id": "UUIDv7", "name": "Новое", "about": null, "is_public": true, "is_chat": true }
```

*Только владелец.* Ответ — пустой.

## `[meet]: open` — войти в конференцию

```json
{ "meet_id": "UUIDv7" }
```

Соединение подписывается на комнату `meet::<meet_id>`, остальные участники получают push `[meet]: user enter`.

Ответ — объект [Meet](../../objects/meet.md) (meta) + `token` — JWT для подключения к LiveKit
(комната `meet::<meet_id>`, роли — публикация и подписка).

## `[meet]: close` — покинуть конференцию

```json
{ "meet_id": "UUIDv7" }
```

Соединение отписывается от комнаты `meet::<meet_id>`, остальные участники получают push `[meet]: user exit`.
Ответ — пустой.

## `[meet]: add cast to meet` — вывести трансляцию в конференцию

```json
{ "meet_id": "UUIDv7", "cast_id": "UUIDv7" }
```

*Только владелец.* Трансляция должна идти (ошибка `CAST_NOT_FOUND`). Ответ — пустой.

## `[meet]: remove cast from meet` — убрать трансляцию из конференции

```json
{ "ingress_id": "...", "meet_id": "UUIDv7" }
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `ingress_id` | `string` | Идентификатор входящего потока (Ingress) трансляции в комнате LiveKit. |
| `meet_id` | `UUIDv7` | Конференция. |

*Только владелец.* Трансляция должна быть активна (ошибка `INGRESS_NOT_FOUND`). Ответ — пустой.

## `[meet]: remove participant` — исключить участника из конференции

```json
{ "meet_id": "UUIDv7", "participant_id": "..." }
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `meet_id` | `UUIDv7` | Конференция. |
| `participant_id` | `string` | Identity участника в комнате LiveKit: `user_id` для пользователя, `cast-<cast_id>` для трансляции. |

*Только владелец.* Исключает себя нельзя (`CANNOT_REMOVE_OWNER`). Если участника
уже нет в комнате или трансляция уже отключена — ошибка `PARTICIPANT_NOT_FOUND`.
Все клиенты комнаты получают LiveKit-событие отключения участника, дополнительный
push не требуется. Ответ — пустой.

## `[meet]: mute participant` — заблокировать источники участнику

```json
{
  "meet_id": "UUIDv7",
  "participant_id": "...",
  "blocks": { "audio": true, "video": false, "screen": false }
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `meet_id` | `UUIDv7` | Конференция. |
| `participant_id` | `string` | Identity участника в комнате LiveKit. |
| `blocks.audio` | `boolean` | Запретить микрофон. |
| `blocks.video` | `boolean` | Запретить камеру. |
| `blocks.screen` | `boolean` | Запретить демонстрацию экрана (вместе с системным звуком). |

*Только владелец.* Блокировка жёсткая: пока владелец её не снимет, участник не
сможет включить источник обратно. Флаги задаются в **итоговом** виде, а не
переключаются — клиент всегда присылает все три.

Ограничения: себя блокировать нельзя (`CANNOT_BLOCK_SELF`), трансляции
(`cast-*`) — `PARTICIPANT_NOT_FOUND`, состояние совпадает с текущим —
`NOTHING_TO_CHANGE`. Неизвестное поле в `blocks` или не-объект `blocks` —
`INVALID_BLOCKS`.

Ответ — пустой. Всем клиентам комнаты разлетается LiveKit-событие
`RoomMetadataChanged` с обновлённым `room.metadata` (см.
[состояние комнаты](#состояние-комнаты)).

## `[meet]: mute all participants` — заблокировать источники всем

```json
{
  "meet_id": "UUIDv7",
  "blocks": { "audio": true, "video": false, "screen": false }
}
```

Поля те же, что у `[meet]: mute participant`. Отличия от точечного запроса:

- применяется ко всем участникам комнаты, кроме организатора и трансляций;
- флаг, **который не прислали**, у конкретного участника сохраняется —
  массовое действие не стирает ранее выставленные точечные блокировки;
- если в комнате не осталось никого, кроме организатора, — `NOTHING_TO_CHANGE`.

Ответ — пустой. Состояние разлетается через `RoomMetadataChanged`.

## `[meet]: set layout` — принудительный режим сетки

```json
{
  "meet_id": "UUIDv7",
  "layout": "grid"
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `meet_id` | `UUIDv7` | Конференция. |
| `layout` | `string \| null` | Режим: `grid`, `spotlight`, `sidebar`, `presentation`. `null` — **снять** принудительный режим. |

*Только владелец.* Ключ `layout` обязан присутствовать, но `null` — осмысленное
значение, а не ошибка: снимает принудительный режим и возвращает участникам
право выбирать раскладку самим. Без него снять режим было нечем (единственный
способ — пересоздать комнату). Строка берётся из белого списка
`MeetManager.LAYOUTS`, иначе в `metadata` комнаты попал бы мусор, который
клиент не смог бы отрисовать — `INVALID_LAYOUT`. Отсутствие ключа —
`LAYOUT_REQUIRED`; пустая строка — это уже `INVALID_LAYOUT`, то есть «ключ
есть, но значение негодное».

```json
{ "layout": "grid" }
```

Навязанный режим перекрывает личный выбор участника: сначала
применяется `room.metadata`, и только если он выключен — `localLayout` из
`sessionStorage`. Поэтому участник не может вернуть свой режим, пока владелец
не снимет принудительный. Ключ `layout` при снятии **удаляется** из
`metadata`, а не пишется как `null`: «режима нет» и «режим ещё не задавали» —
одно и то же состояние.

## Состояние комнаты

Блокировки и принудительный режим сетки хранятся в `metadata` комнаты
LiveKit. Сбрасываются вместе с комнатой,
когда из неё вышли все.

```json
{
  "layout": "grid",
  "blocks": {
    "<participant_identity>": { "audio": true, "video": false, "screen": false }
  }
}
```

Клиент читает `room.metadata` при входе и слушает `RoomEvent.RoomMetadataChanged`.

## `[meet]: remove` — удалить конференцию

```json
{ "meet_id": "UUIDv7" }
```

*Только владелец.* Конференция помечается удалённой. Ответ — пустой.

## `[meet]: create invite` — приглашение

```json
{ "meet_id": "UUIDv7", "name": "Для команды", "max_users": 0 }
```

`max_users`: `0` — без лимита. Ответ — объект [Invite](../../objects/invite.md).

## `[meet]: get invites` — список приглашений

```json
{ "meet_id": "UUIDv7", "direction": "next", "cursor_id": null, "offset": 100 }
```

`offset` — диапазон 1–300. Ответ — массив [Invite](../../objects/invite.md) **и** поле `has_more: boolean` — есть ли продолжение в сторону `direction` (для первой загрузки — есть ли продолжение после страницы).

## `[meet]: get upload thumb url` — ссылка для загрузки обложки

```json
{ "file_name": "cover.jpg", "meet_id": "UUIDv7", "mime_type": "image/jpeg", "size": 102400 }
```

Ответ — цели загрузки: `{ "targets": [...], "document_id": "UUIDv7" }` —
**только оригинал**, производные ассеты создаст сервер. Загрузите цель
`POST`-ом по её `url` (см.
[руководство по файлам](../../guides/upload.md)).

## `[meet]: save thumb` — сохранить обложку

```json
{ "document_id": "UUIDv7", "meet_id": "UUIDv7" }
```

Вызывается после загрузки оригинала. Сервер проверяет оригинал в хранилище,
генерирует производные ассеты и отвечает готовым объектом — ожидание
обработки может занять до ~100 секунд, таймаут запроса должен быть
**не меньше 120 секунд**. Повторный вызов идемпотентен. Ответ —
токенизированный объект файла ([objects/file.md](../../objects/file.md)).
