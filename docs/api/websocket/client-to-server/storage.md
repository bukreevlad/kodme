# storage — обработка файлов

События раздела `[storage]`.

## `[storage]: abort upload` — отменить загрузку

Клиент зовёт это, когда пользователь прервал загрузку (кнопка отмены на
прогресс-баре). Сервер помечает запись терминальным статусом `aborted` и
перестаёт ждать объекты S3. Отмена идемпотентна: записи уже нет — ответ всё
равно успешный.

```json
{ "document_id": "UUIDv7" }
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `document_id` | `UUIDv7` | Id документа из ответа `*: get upload url`. |

Ответ:

```json
{
  "status": true,
  "data": { "status": "aborted", "document_id": "UUIDv7" }
}
```

Чужой документ отменить нельзя: сервер вернёт ошибку `ACCESS_DENIED`
(`124242`).

## Метадата файла (контракт v2)

Контракт описывает формат метадаты, которую сервер собирает **после
загрузки** по реальному файлу (превью, рендерации, LQIP, цвета, форма
волны) и сохраняет в `documents.metadata`. Формат одинаков для всех файлов:
вложений сообщений и комментариев, стикеров, аватарок, обложек и облака.

В запросах `*: get upload url` поле `metadata` передают только **вложения
сообщений/комментариев и стикеры** — там это флаги (`flags`, например
голосовой заметки), а контракт ниже целиком не требуется. Для **аватарок,
обложек и файлов облака** поле не передаётся: производные ассеты создаёт
сервер после события сохранения (`save avatar` / `save thumb` /
`save file`).

Пример полного контракта:

```json
{
  "v": 2,
  "kind": "image",
  "original": {
    "mime": "image/jpeg",
    "size": 512345,
    "width": 1600,
    "height": 1200,
    "duration": null
  },
  "thumbnails": [
    { "width": 400, "size": 5123 },
    { "width": 800, "size": 9123 }
  ],
  "renditions": [],
  "wave_form": [0.1, 0.9, 0.3],
  "placeholder": "data:image/webp;base64,<...>",
  "colors": {
    "dominant": "#ff8800",
    "accent": "#002244",
    "is_dark": false,
    "source": "image"
  },
  "tags": { "title": "Дорожка", "artist": "Исполнитель", "album": "Альбом" },
  "flags": { "is_audio_note": false, "is_video_note": false }
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `v` | `number` | Версия контракта: только `2`. |
| `kind` | `string` | `image` / `audio` / `audio_note` / `video` / `video_note` / `document`. Сервер перепроверяет: несовместимая с типом файла категория заменяется на серверную. |
| `original.mime` | `string` | MIME оригинала. Сверяется с расширением имени файла; при несовпадении — `MIME_EXTENSION_MISMATCH`. |
| `original.size` | `number` | Размер оригинала в байтах. Обязателен, целое `0..524288000`; иначе `INVALID_FILE_SIZE`. |
| `original.width` / `height` | `number` | Размеры в пикселях, `1..20000`. Отсутствуют — `0`. Вне диапазона — `INVALID_MEDIA_METADATA`. |
| `original.duration` | `number \| null` | Секунды, только для аудио/видео, `0..86400`. Для изображений всегда `null`. |
| `thumbnails` | `array` | До 3 элементов `{ width, size }`. Ширина только из `400`/`800`/`1200` и меньше ширины оригинала (для изображений/видео). Дубли и чужие ширины молча отбрасываются; массив длиннее 3 — `INVALID_MEDIA_METADATA`. |
| `renditions` | `array` | До 3 элементов `{ label, width, size }`. Только видео, `label` из `360`/`720`/`1080`, ширина меньше оригинала. |
| `wave_form` | `array` | Только аудио: форма волны, ровно 60 точек `0..1`. Для остальных — `null`. |
| `placeholder` | `string` | LQIP: `data:image/webp;base64,<...>`. Декодированная длина не более 4096 байт (`INVALID_PLACEHOLDER`); неверный формат — `INVALID_MEDIA_METADATA`. |
| `colors` | `object \| null` | Акцентные цвета: `dominant`/`accent` — `#rrggbb`, `is_dark` — boolean, `source` — `image`/`video_frame`/`audio_cover`. Битые значения молча отбрасываются. |
| `tags` | `object \| null` | Строки `title`/`artist`/`album`, обрезаются до 256 символов. |
| `flags` | `object` | `is_audio_note` / `is_video_note` — boolean. |

Неизвестные ключи контракта игнорируются. Значения полей — факты
реального файла: превью и рендерации получают `height`, `mime_type`,
`object_path`, у оригинала — факты `size`/`mime` из хранилища и
`aspect_ratio`.

### Цели загрузки

Ответ `*: get upload url` содержит `targets[]` — по одной цели на объект.
Выдаётся **только оригинал** (`kind: "original"`): производные ассеты
создаёт сервер при событии сохранения (`save attach` / `save sticker` /
`save avatar` / `save thumb` / `save file`). Каждая цель — свой `url`,
`fields`, `mime_type` и `max_size`.

## Ошибки

Подготовка загрузки (`*: get upload url`), сохранение вложения
(`save attach`) и финальное сохранение (`send`, `save avatar`, `save thumb`,
`save file`) возвращают ошибки штатным образом.
Коды:

- `FILE_NAME_REQUIRED` / `FILE_NAME_TOO_LONG` — нет/битое/слишком длинное имя файла.
- `FILE_SIZE_REQUIRED` — не передан размер.
- `INVALID_FILE_SIZE` — размер не целое число байт или вне допустимого диапазона.
- `MIME_TYPE_REQUIRED` — не передан MIME.
- `INVALID_MIME_TYPE` — MIME вне справочника.
- `MIME_EXTENSION_MISMATCH` — MIME не совпадает с расширением имени файла.
- `INVALID_EXTENSION` — расширение имени файла вне белого списка.
- `INVALID_METADATA` — метадата слишком глубокая/большая (битые данные).
- `INVALID_MEDIA_METADATA` (`124244`) — метадата v2 не прошла белый список
  (поле/значение вне контракта).
- `INVALID_PLACEHOLDER` (`124245`) — LQIP больше 4096 байт.
- `ACCESS_DENIED` — нет права на запись (нет права отправлять сообщения в
  канал и т.п.).

Ошибки финального сохранения (после загрузки файлов в S3):

- `DOCUMENT_NOT_FOUND` (`124250`) — документ не найден (истёк TTL и т.п.).
- `ACCESS_DENIED` (`124251`) — документ загружал другой пользователь или для
  другой сущности.
- `INVALID_MEDIA_METADATA` (`124252`) — метадата записи повреждена.
- `INVALID_PLACEHOLDER` (`124253`) — LQIP в записи повреждён.
- `UPLOAD_SIZE_MISMATCH` (`124254`) — фактический размер объекта в S3 не
  совпал с заявленным.
- `UPLOAD_MIME_MISMATCH` (`124255`) — фактический MIME объекта не согласуется
  с расширением и заявленным MIME.
- `THUMBNAIL_MISSING` (`124256`) — превью заявлено в метадате, но не докачано.
- `RENDITION_MISSING` (`124257`) — рендерация заявлена, но не докачана.
- `OBJECT_NOT_UPLOADED` (`124258`) — объект не загружен (например, сам оригинал).
- `MEDIA_PROCESSING_FAILED` (`124259`) — обработка файла не удалась или не
  уложилась в отведённое время; повторите событие сохранения ещё раз.
- `MEDIA_PROCESSING_DISABLED` (`124260`) — серверная обработка файлов
  временно отключена; аватар, обложку или стикер сейчас сохранить нельзя.
  (Вложения при этом сохраняются — см. `processed: false` в
  [messages.md](./messages.md).)
