# bots — настройки бота

События раздела `[bot]` для соединения самого бота. В отличие от клиентского
раздела `[bot]`, здесь бот управляет **собственным** аватаром и меню
(без прав владельца).

## `[bot]: get upload avatar url` — ссылка для загрузки аватара

```json
{ "file_name": "avatar.jpg", "mime_type": "image/jpeg", "size": 102400 }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `file_name` | `string` | `""` | Имя файла. |
| `mime_type` | `string` | — | MIME-тип; сверяется с расширением. |
| `size` | `number` | — | Размер файла в байтах. |

Ответ — цели для прямой загрузки в облачное хранилище (**только оригинал** —
производные ассеты создаст сервер при сохранении):

```json
{
  "targets": [
    {
      "path": "users/<bot_user_id>/photoalbums/<album_id>/<uuid>/<uuid>.jpg",
      "kind": "original",
      "url": "https://...presigned.url",
      "fields": { "key": "...", "Policy": "..." },
      "mime_type": "image/jpeg",
      "max_size": 524288000
    }
  ],
  "document_id": "UUIDv7"
}
```

## `[bot]: save avatar` — сохранить аватар из загруженного файла

```json
{ "document_id": "UUIDv7" }
```

Сервер проверяет оригинал в хранилище, генерирует производные ассеты и
отвечает готовым объектом — ожидание обработки может занять до ~100 секунд,
таймаут запроса должен быть **не меньше 120 секунд**. Повторный вызов
идемпотентен. Ответ — объект [File](../../objects/file.md) с токеном доступа
(`document_id`, `url`, `token`).

## `[bot]: set avatar` — установить аватар из существующего документа

```json
{ "document_id": "UUIDv7" }
```

Ответ — объект [File](../../objects/file.md) с токеном доступа. Аналогично
`[bot]: save avatar`, но документ уже должен существовать в хранилище
(ранее загруженный через `[bot]: get upload avatar url` или
`[message]: get upload attach url`).

Ошибки: `DOCUMENT_NOT_FOUND` (документ не найден или не принадлежит боту).

## `[bot]: remove avatar` — удалить аватар бота

Событие без полей:

```json
{}
```

Снимает ссылку на аватар бота: файл и документ не удаляются, аватар
перестаёт отображаться. Повторный вызов идемпотентен (отсутствие аватара —
не ошибка). Ответ — пустой.

## `[bot]: set menu` — сохранить меню бота

```json
{ "menu": "[{\"text\":\"Помощь\"},{\"text\":\"Цены\"}]" }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `menu` | `string` | — | Меню бота — строка (JSON-представление списка команд). |

Ответ — пустой. Меню сохраняется в настройках бота.
