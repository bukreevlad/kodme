# broadcasts — трансляции бота

События раздела `[broadcast]` для соединения бота. Бот может создавать трансляции
и управлять ими как владелец. Контракты совпадают с клиентскими версиями
(см. [broadcasts.md](../client-to-server/broadcasts.md)).

## `[broadcast]: create` — создать трансляцию

```json
{ "name": "Стрим", "about": "Описание", "is_public": true, "is_chat": true }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | `""` | Название. |
| `about` | `string \| null` | `""` | Описание. |
| `is_public` | `boolean` | `true` | Публичность. |
| `is_chat` | `boolean` | `true` | Включить чат трансляции. |

Ответ: `{ "cast_id": "UUIDv7" }`.

## `[broadcast]: remove` — удалить трансляцию

```json
{ "cast_id": "UUIDv7" }
```

Только создатель трансляции — бот удаляет **созданные им** трансляции
(проверка по `created_user_id`; чужие и трансляции, созданные его
владельцем из клиента, — `ACCESS_DENIED`). Удаляет трансляцию и её
чат-канал. Ответ — пустой.

Владелец бота трансляции бота из клиента **не видит в управлении**:
он может смотреть только публичные трансляции (как любой пользователь),
удалять и менять их настройки может только бот.

## `[broadcast]: get casts` — список трансляций бота

```json
{ "direction": null, "cursor_id": null, "offset": 35 }
```

Поля пагинации — как у клиентского `[broadcast]: get casts`
(см. [broadcasts.md](../client-to-server/broadcasts.md)). Ответ — массив
meta созданных ботом трансляций **и** поле `has_more`. Бот видит только
созданные им трансляции (публичные чужие и подписки не возвращаются).

## `[broadcast]: get watch token` — токен просмотра

```json
{ "cast_id": "UUIDv7" }
```

Контракт совпадает с клиентским `[broadcast]: open`: проверка доступа
(публичная трансляция, владелец или подписанный участник), подписка
соединения бота на комнату `broadcast::<cast_id>` (дальше приходят
события статуса) и ответ — meta трансляции с полем `access_token` —
**токен просмотра** для плеера (hls-ссылка WebApp). Ошибки:
`ACCESS_DENIED` (доступ закрыт), `VIEW_TOKEN_GENERATION_FAILED`.

## `[broadcast]: create invite` — приглашение в трансляцию

```json
{ "cast_id": "UUIDv7", "name": "Для друзей", "max_users": 0 }
```

Только для трансляций, созданных ботом (проверка по `created_user_id`).
`max_users`: `0` — без лимита, диапазон 0–1000. Ответ — объект
[Invite](../../objects/invite.md): поле `link` — код приглашения,
поле `url` — **готовая полная ссылка** (`<host>/+<link>`), которую можно
сразу отправлять пользователю. Позволяет боту создать приватную
трансляцию и выдать на неё приглашение.

## `[broadcast]: get settings` — настройки трансляции

```json
{ "cast_id": "UUIDv7" }
```

Только владелец. Ответ — объект [Broadcast](../../objects/broadcast.md) (meta) + поле
`token` (токен для подключения трансляции к серверу).

## `[broadcast]: get upload thumb url` — ссылка для загрузки обложки

```json
{ "file_name": "thumb.jpg", "cast_id": "UUIDv7", "mime_type": "image/jpeg", "size": 102400 }
```

Ответ — цели для прямой загрузки (**только оригинал** — производные ассеты
создаст сервер при сохранении):

```json
{ "targets": [...], "document_id": "UUIDv7" }
```

Загрузите каждую цель `POST`-ом по её `url` (см.
[руководство по файлам](../../guides/upload.md)).

## `[broadcast]: save thumb` — сохранить обложку из загруженного файла

```json
{ "document_id": "UUIDv7", "cast_id": "UUIDv7" }
```

Сервер проверяет оригинал в хранилище, генерирует производные ассеты и
отвечает готовым объектом — ожидание обработки может занять до ~100 секунд,
таймаут запроса должен быть **не меньше 120 секунд**. Повторный вызов
идемпотентен. Ответ — объект [File](../../objects/file.md) с токеном доступа.

## `[broadcast]: set thumb` — установить обложку из существующего документа

```json
{ "document_id": "UUIDv7", "cast_id": "UUIDv7" }
```

Только владелец. Ответ — объект [File](../../objects/file.md) с токеном доступа.
Документ должен уже существовать в хранилище.

Ошибки: `DOCUMENT_NOT_FOUND` (документ не найден или не принадлежит владельцу).

## `[broadcast]: save settings` — изменить настройки

```json
{ "cast_id": "UUIDv7", "name": "Новое", "about": null, "is_public": true, "is_chat": true }
```

Только владелец. Ответ — пустой.
