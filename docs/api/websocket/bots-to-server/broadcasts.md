# broadcasts — трансляции бота

События раздела `[broadcast]` для соединения бота. Бот может создавать трансляции
и управлять ими как владелец. Контракты совпадают с клиентскими версиями
(см. [broadcasts.md](../client-to-server/broadcasts.md)).

## `[broadcast]: create` — создать трансляцию

```json
{ "name": "Стрим", "about": "Описание", "is_public": true, "is_chat": true }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | `""` | Название. |
| `about` | `string \| null` | `""` | Описание. |
| `is_public` | `boolean` | `true` | Публичность. |
| `is_chat` | `boolean` | `true` | Включить чат трансляции. |

Ответ: `{ "cast_id": "UUIDv7" }`.

## `[broadcast]: get settings` — настройки трансляции

```json
{ "cast_id": "UUIDv7" }
```

Только владелец. Ответ — объект [Broadcast](../../objects/broadcast.md) (meta) + поле
`token` (токен для подключения трансляции к серверу).

## `[broadcast]: get upload thumb url` — ссылка для загрузки обложки

```json
{ "file_name": "thumb.jpg", "cast_id": "UUIDv7", "mime_type": "image/jpeg", "size": 102400 }
```

Ответ — цели для прямой загрузки (**только оригинал** — производные ассеты
создаст сервер при сохранении):

```json
{ "targets": [...], "document_id": "UUIDv7" }
```

Загрузите каждую цель `POST`-ом по её `url` (см.
[руководство по файлам](../../guides/upload.md)).

## `[broadcast]: save thumb` — сохранить обложку из загруженного файла

```json
{ "document_id": "UUIDv7", "cast_id": "UUIDv7" }
```

Сервер проверяет оригинал в хранилище, генерирует производные ассеты и
отвечает готовым объектом — ожидание обработки может занять до ~100 секунд,
таймаут запроса должен быть **не меньше 120 секунд**. Повторный вызов
идемпотентен. Ответ — объект [File](../../objects/file.md) с токеном доступа.

## `[broadcast]: set thumb` — установить обложку из существующего документа

```json
{ "document_id": "UUIDv7", "cast_id": "UUIDv7" }
```

Только владелец. Ответ — объект [File](../../objects/file.md) с токеном доступа.
Документ должен уже существовать в хранилище.

## `[broadcast]: save settings` — изменить настройки

```json
{ "cast_id": "UUIDv7", "name": "Новое", "about": null, "is_public": true, "is_chat": true }
```

Только владелец. Ответ — пустой.
