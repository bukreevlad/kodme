# bot-app — события WebApp-приложений бота

События раздела `[bot-app]` приходят в соединение бота, когда пользователь
отправляет данные из WebApp-приложения бота. Источник данных — клиентское
событие `[bots-apps]: send data` (см.
[client-to-server/bots-apps.md](../client-to-server/bots-apps.md)).

## `[bot-app]: send data` — данные из приложения

```json
{
  "type": "event",
  "event": "[bot-app]: send data",
  "data": {
    "socket_id": "...",
    "user_id": "UUIDv7",
    "bot_app_id": "UUIDv7",
    "data": "..."
  }
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `socket_id` | `string` | Id соединения пользователя, отправившего данные. |
| `user_id` | `UUIDv7` | Id пользователя. |
| `bot_app_id` | `UUIDv7` | Id приложения, из которого пришли данные. |
| `data` | `string` | Данные приложения (непустая строка до 8000 символов). |

Событие доставляется **в соединение** (не в топик) и только когда бот
подключён: иначе отправитель получает ошибку `BOT_NOT_IN_NETWORK`.
