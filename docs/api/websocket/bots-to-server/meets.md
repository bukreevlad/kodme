# meets — конференции бота

События раздела `[meet]` для соединения бота. Бот может создавать конференции
и управлять ими как владелец. Контракты совпадают с клиентскими версиями
(см. [meets.md](../client-to-server/meets.md)).

Правила доступа как у трансляций: управлять (настройки, обложка, приглашения,
удаление) может **только создатель** конференции — бот удаляет и меняет
только созданные им конференции; владелец бота из клиента доступа не имеет.

## `[meet]: create` — создать конференцию

```json
{ "name": "Совещание", "about": "Описание", "is_public": true, "is_chat": true }
```

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `name` | `string` | — | Название. |
| `about` | `string \| null` | `""` | Описание. |
| `is_public` | `boolean` | `true` | Публичность. |
| `is_chat` | `boolean` | `true` | Включить чат конференции. |

Ответ: `{ "meet_id": "UUIDv7" }`.

## `[meet]: remove` — удалить конференцию

```json
{ "meet_id": "UUIDv7" }
```

Только создатель — бот удаляет **созданные им** конференции (и их
чат-канал). Ответ — пустой. Ошибка: `ACCESS_DENIED`.

## `[meet]: get meets` — список конференций бота

```json
{ "direction": null, "cursor_id": null, "offset": 35 }
```

Поля пагинации — как у клиентского `[meet]: get meets` (см.
[meets.md](../client-to-server/meets.md)). Ответ — массив meta созданных
ботом конференций **и** поле `has_more`. Бот видит **только созданные им**
конференции (публичные чужие не возвращаются).

## `[meet]: create invite` — приглашение в конференцию

```json
{ "meet_id": "UUIDv7", "name": "Для команды", "max_users": 0 }
```

Только для конференций, созданных ботом. `max_users`: `0` — без лимита,
диапазон 0–1000. Ответ — объект [Invite](../../objects/invite.md):
поле `url` — **готовая полная ссылка** (`<host>/+<link>`), которую можно
сразу отправлять пользователю.

## `[meet]: get settings` — настройки конференции

```json
{ "meet_id": "UUIDv7" }
```

Только создатель. Ответ — объект [Meet](../../objects/meet.md) (meta).

## `[meet]: save settings` — изменение настроек

```json
{ "meet_id": "UUIDv7", "name": "Новое", "about": null, "is_public": true, "is_chat": true }
```

Только создатель. Ответ — пустой.

## `[meet]: get upload thumb url` — ссылка для загрузки обложки

```json
{ "file_name": "cover.jpg", "meet_id": "UUIDv7", "mime_type": "image/jpeg", "size": 102400 }
```

Только создатель. Ответ — цели загрузки: `{ "targets": [...], "document_id": "UUIDv7" }` —
**только оригинал**, производные ассеты создаст сервер (см.
[руководство по файлам](../../guides/upload.md)).

## `[meet]: save thumb` — сохранить обложку

```json
{ "document_id": "UUIDv7", "meet_id": "UUIDv7" }
```

Только создатель. Вызывается после загрузки оригинала; ожидание обработки
может занять до ~100 секунд — таймаут запроса **не меньше 120 секунд**.
Ответ — токенизированный объект файла ([objects/file.md](../../objects/file.md)).

## `[meet]: remove thumb` — удалить обложку

```json
{ "meet_id": "UUIDv7" }
```

Только создатель. Снимает ссылку на обложку (файл не удаляется),
идемпотентно. Ответ — пустой.
