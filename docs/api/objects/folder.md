# Folder — папка каналов

```json
{ "id": "UUIDv7", "created_user_id": "UUIDv7", "name": "Работа" }
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `UUIDv7` | Id папки. |
| `created_user_id` | `UUIDv7` | Владелец. |
| `name` | `string` | Название, 2–128 символов (кириллица/латиница/общие символы). |
