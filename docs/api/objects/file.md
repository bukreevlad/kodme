# File — токенизированный файл

Файл (документ), выданный клиенту вместе с временным **токеном доступа**.

```json
{
  "id": "UUIDv7",
  "file_name": "photo.jpg",
  "extname": ".jpg",
  "metadata": { "?": "Серверные метаданные документа" },
  "mime_type": "image/jpeg",
  "size": 2048576,
  "token": "<JWT: download-file>"
}
```

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | `UUIDv7` | Id документа. |
| `file_name` | `string` | Имя файла. |
| `extname` | `string` | Расширение (например `.jpg`, `.mp4`). |
| `metadata` | `object \| null` | Метаданные документа (зависят от типа). |
| `mime_type` | `string` | MIME-тип (например `image/jpeg`, `video/mp4`). |
| `size` | `int` | Размер в байтах. |
| `token` | `string` | JWT доступа к файлу (тип `download-file`), короткоживущий. |

## Скачивание

Файл скачивается по HTTP (без WebSocket):

```
GET /api/v1/storage/:document?token=<token>&size=...&rendition=...
```

Токен передаётся также заголовком `x-file-token: Bearer <token>`. Опциональные
параметры: `size` — ширина превью изображения (`400`/`800`/`1200`, путь
`{папка}/<size>.webp`); `rendition` — метка видео-рендерации
(`360`/`720`/`1080`, путь `{папка}/q/<label>.mp4`; неизвестная метка не ошибка —
отдаётся оригинал). Сервер отвечает редиректом (302) на временный presigned URL
хранилища. Подробнее — [http/storage.md](../http/storage.md).

## Примечания

- Токен короткоживущий (по умолчанию несколько минут; точно — конфигурация сервера).
- Если токен протух, сервер при скачивании может его перевыпустить автоматически
  (см. storage) — клиенту достаточно повторить запрос.
- В некоторых местах API отдаётся **сокращённая** форма файла — только связка
  `document_id` + `token` (например, `avatar` в отдельных ответах). В актуальных
  версиях сервера поле аватара в объектах [User](./user.md)/[Channel](./channel.md)
  — полный объект файла.
